Accuracy

No invented facts.
Ever.

Every number comes from the fact bank. Metrics never migrate between employers. When strict mode is on, unverified numbers are omitted entirely.

Clients, regions, tools, team sizes — none are invented. If a role lacks material, the engine writes qualitative bullets and flags them. It never fills gaps with fiction.
