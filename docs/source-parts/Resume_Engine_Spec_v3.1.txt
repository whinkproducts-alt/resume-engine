## 1. Product overview
Resume Engine is a public SaaS that takes a job description (JD) as input and produces a tailored, ATS-optimized Word resume (.docx) as output. 
Admin: One admin account (Whinkproducts@gmail.com) with unlimited runs, admin panel access, and no billing. Provisioned via environment variables only.

## 2. Roles, permissions, quotas
enum UserRole { USER PRO AGENCY ADMIN }
- USER: 1 profile, per-credit runs
- PRO: 3 profiles, 10 runs/month
- AGENCY: Unlimited profiles, unlimited runs
- ADMIN: Everything, unlimited, no billing, admin panel

async function assertCanRun(user: User) {
  if (user.isAdmin && user.adminUnlimited) return; // bypass
  if (user.role === 'AGENCY') return;
  if (user.role === 'PRO') {
    const used = await usageCount(user.id, currentMonth());
    if (used >= 10) throw new AppError('RUN_LIMIT_REACHED', 402);
    return;
  }
  const credits = await remainingCredits(user.id);
  if (credits < 1) throw new AppError('NO_CREDITS', 402);
}

## 3. Authentication & admin provisioning
### 3.1 Standard auth
- Argon2id hashing (m=64MB, t=3, p=4).
- Password: min 12 chars, upper + lower + digit + symbol.
- Access: JWT (HS256 or RS256), 15-min TTL, claims { sub, role, isAdmin, iat, exp, jti }.
- Refresh: 256-bit random, hashed SHA-256 in Session, 30-day TTL.
- Brute force: standard 10 attempts / 15 min / IP; admin 5 attempts / 15 min / IP.

### 3.3 Admin provisioning — no hardcoded passwords
Environment variables, set only in the hosting provider's secret store:
ADMIN_EMAIL=Whinkproducts@gmail.com
ADMIN_SEED_PASSWORD=<set a strong unique password here>
ADMIN_BOOTSTRAP_TOKEN=<random 32-byte base64>

Startup hook (apps/api/src/auth/bootstrap-admin.ts), runs at boot before traffic:
export async function ensureAdmin() {
  const email = process.env.ADMIN_EMAIL;
  if (!email) return;
  const existing = await prisma.user.findUnique({ where: { email } });
  if (existing) {
    if (!existing.isAdmin) {
      await prisma.user.update({
        where: { id: existing.id },
        data: { isAdmin: true, adminUnlimited: true, role: 'ADMIN' },
      });
    }
    return;
  }
  const password = process.env.ADMIN_SEED_PASSWORD;
  if (!password) throw new Error('ADMIN_SEED_PASSWORD required on first boot');
  await prisma.user.create({
    data: {
      email,
      passwordHash: await argon2.hash(password),
      firstName: 'Victor',
      lastName: 'Igboekwe',
      role: 'ADMIN',
      isAdmin: true,
      adminUnlimited: true,
      emailVerified: true,
      mustChangePassword: process.env.NODE_ENV === 'production',
    },
  });
}
Bootstrap endpoint (idempotent, for fresh environments):
POST /auth/bootstrap-admin
Rules: Only succeeds if users.count == 0 OR X-Bootstrap-Token matches ADMIN_BOOTSTRAP_TOKEN.

## 5. Pipeline — stages 0 through 8
STAGE 0 — QUOTA GATE: assertCanRun(user).
STAGE 1 — INGEST: sourceType: paste | file | url. If <200 chars → FAILED (JD_UNUSABLE).
STAGE 2 — ANALYZE: LLM outputs company, roleTitle, location, seniority, industryTags[], topKeywords[25], responsibilities[], requirements[], companyInferred, companyConfidence.
STAGE 3 — CONFIRM: If companyInferred OR confidence < 0.75 → AWAITING_COMPANY_CONFIRM.
STAGE 4 — REWRITE: Staged LLM calls. headline (R2,R3), summary (R4,R20), competencies (R5), roles (R6,R8-R12,R19), keywords (R14,R15), targets (R16).
STAGE 5 — ASSEMBLE: Merge sections. Copy header (R1), education/certs/dates (R7,R13). Apply contactLocationOverride.
STAGE 6 — VALIDATE: Run R1-R20. Fact bank check. Claims check. Style lint.
STAGE 7 — RENDER: docx npm. If AGENCY: inject BrandingConfig.
STAGE 8 — EXPORT & QA: Upload DOCX to S3. LibreOffice PDF. Page count. Upload PDF.
